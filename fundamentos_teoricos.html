2  Fundamentos Teóricos

En este capítulo se presentarán las bases conceptuales y el marco formal del cálculo estocástico que fundamentan el desarrollo de nuestro modelo matemático para la red de frío. Se definirán en primer lugar los procesos estocásticos elementales para, posteriormente, construir la ecuación diferencial estocástica (EDE) híbrida que rige el sistema.

2.1 Procesos Estocásticos

El modelado térmico de un refrigerador de vacunas expuesto a incertidumbres continuas y perturbaciones discretas requiere herramientas más allá del cálculo determinista. Desde una perspectiva analítica, un proceso estocástico representa la generalización de una variable aleatoria indexada en un conjunto ordenado, parametrizando la evolución de un sistema bajo incertidumbre.

Definición 2.1 (Proceso Estocástico) Sea \((\Omega, \mathcal{F}, \mathbb{P})\) un espacio de probabilidad y sea \(\mathcal{S} \subseteq \mathbb{R}^d\) un espacio muestral dotado de su respectiva \(\sigma\)-álgebra de Borel. Un proceso estocástico es una familia de variables aleatorias \(\{X_t\}_{t \in \mathcal{T}}\) parametrizadas por \(t \in \mathcal{T}\), donde \(\mathcal{T} \subseteq \mathbb{R}\).

Dependiendo de como es el conjunto de índices \(\mathcal{T}\), los procesos estocásticos se clasifican en dos:

  1. Procesos estocásticos a tiempo discreto: Si \(\mathcal{T}\) es numerable, por lo general \(\mathcal{T} = \mathbb{N}_0 = \{0, 1, 2, \dots\}\) o \(\mathcal{T} = \mathbb{Z}\), decimos que el proceso estocástico es a tiempo discreto. En este escenario, el sistema evoluciona mediante transiciones discretas en pasos fijos discretizados.
  2. Procesos estocásticos a tiempo continuo: Si \(\mathcal{T}\) es un intervalo de \(\mathbb{R}\), por lo general \(\mathcal{T} = [0, \infty)\) o un intervalo acotado \(\mathcal{T} = [0, T]\), \(T > 0\), se dice que el proceso estocástico es a tiempo continuo. Esta estructura es la adecuada para modelar fenómenos físicos continuos, como la transferencia térmica.

Para enlazar la teoría probabilística con la observación empírica de un fenómeno estocástico, es indispensable establecer la distinción entre el espacio funcional del proceso y sus realizaciones particulares.

Definición 2.2 (Trayectorias del Proceso Estocástico) Si \(\{X_t\}_{t \geq 0}\) es un proceso estocástico a tiempo continuo, para cada \(\omega \in \Omega\) fijo y \(\mathcal{S} = \mathbb{R}\), se definen las trayectorias del proceso como: \[ \mathcal{T} = [0, \infty) \rightarrow \mathcal{S} = \mathbb{R} \] \[ t \rightarrow X_t(\omega). \]

Las propiedades analíticas de un proceso estocástico, tales como la continuidad, la diferenciabilidad y la presencia de discontinuidades finitas, se definen estrictamente a partir del comportamiento de varias componentes, para más detalles consultar (Karlin y Taylor 1998). Los componentes aleatorios de nuestro sistema se sustentan en tres procesos estocásticos específicos a tiempo continuo.

2.1.1 Movimiento Browniano (Proceso de Wiener)

Para representar las fluctuaciones térmicas continuas de baja intensidad asociadas al ruido intrínseco del termostato y microtransferencias de calor se utiliza el movimiento Browniano.

Definición 2.3 (Proceso de Wiener) Un proceso estocástico a tiempo continuo \(\{W(t)\}_{t \ge 0}\) definido sobre un espacio de probabilidad filtrado \((\Omega, \mathcal{F}, \{\mathcal{F}_t\}, \mathbb{P})\) es un movimiento Browniano estándar o proceso de Wiener si cumple con las siguientes propiedades:

  1. \(W(0) = 0\) con probabilidad 1.
  2. Posee incrementos independientes; es decir, para cualesquiera tiempos \(0 \le t_1 < t_2 < \dots < t_n\), las variables aleatorias \(W(t_2)-W(t_1), \dots, W(t_n)-W(t_{n-1})\) son mutuamente independientes.
  3. Posee incrementos estacionarios gaussianos, es decir, para todo \(t > s \ge 0\), \(W(t) - W(s) \sim \mathcal{N}(0, t-s)\).

El término \(dW(t) = W(t+dt) - W(t)\) representa el diferencial del proceso de Wiener. Este denota una perturbación gaussiana elemental en un intervalo infinitesimal \(dt\), caracterizada por una media \(\mathbb{E}[dW(t)] = 0\) y una varianza \(\mathbb{E}[(dW(t))^2] = dt\). Para una revisión detallada sobre las propiedades de medida y construcciones analíticas de este proceso, se sugiere consultar a (Karatzas y Shreve 1998).

2.1.2 Procesos de Poisson

Las aperturas de las puertas del refrigerador por el personal médico constituyen eventos discretos y repentinos que alteran instantáneamente la temperatura interna. Este tipo de fenómenos se modela mediante un proceso estocástico a tiempo continuo de saltos puros.

Definición 2.4 (Proceso de Poisson Homogéneo) Un proceso estocástico a tiempo continuo \(\{N(t)\}_{t \ge 0}\) que toma valores enteros en el espacio de estados \(\mathcal{S} = \mathbb{N}_0\) es un proceso de Poisson homogéneo con parámetro de intensidad constante \(\lambda > 0\) si satisface las siguientes condiciones:

  1. \(N(0) = 0\) con probabilidad 1.
  2. Posee incrementos independientes; es decir, para cualesquiera tiempos \(0 \le t_1 < t_2 < \dots < t_n\), las variables aleatorias discretas \(N(t_2)-N(t_1), \dots, N(t_n)-N(t_{n-1})\) son mutuamente independientes.
  3. Posee incrementos estacionarios; lo que implica que la ley de probabilidad de cualquier incremento \(N(t+s) - N(s)\) depende únicamente de la amplitud temporal \(t\) y resulta invariante ante traslaciones sobre el origen cronológico \(s\). De forma explícita, la variable aleatoria \(N(t)\) sigue una distribución de Poisson con parámetro o tasa media dada por el producto \(\lambda t\), es decir:

\[ \mathbb{P}(N(t) = n) = \frac{(\lambda t)^n e^{-\lambda t}}{n!}, \quad n = 0, 1, 2, \dots \]

Para formalizar analíticamente el comportamiento probabilístico de los saltos sin recurrir a nociones intuitivas, las probabilidades de transición asociadas al incremento del proceso en un intervalo acotado de longitud \(h > 0\) se especifican rigurosamente mediante el límite asintótico cuando \(h \to 0\):

\[ \mathbb{P}(N(t+h) - N(t) = 1) = \lambda h + o(h) \] \[ \mathbb{P}(N(t+h) - N(t) \ge 2) = o(h) \]

donde la notación algebraico-asintótica de Landau \(o(h)\) denota una función de orden superior tal que \(\lim_{h \to 0} \frac{o(h)}{h} = 0\). Esto garantiza formalmente que la probabilidad de ocurrencia de múltiples eventos simultáneos en una fracción temporal infinitesimal es prácticamente nula.

Sin embargo, en la dinámica real de un centro de salud, la tasa de aperturas del refrigerador no es constante; exhibe una estacionalidad diaria (por ejemplo, mayor actividad en horas pico). Para capturar esta variabilidad, generalizamos el modelo relajando la propiedad de incrementos estacionarios.

Definición 2.5 (Proceso de Poisson No Homogéneo) Un proceso estocástico a tiempo continuo \(\{N(t)\}_{t \ge 0}\) es un proceso de Poisson no homogéneo con función de intensidad \(\lambda(t) \ge 0\) (para \(t \ge 0\)) si satisface las siguientes condiciones:

  1. \(N(0) = 0\) con probabilidad 1.
  2. Posee incrementos independientes.
  3. Para todo \(t \ge 0\) y \(h > 0\), la probabilidad de que ocurra exactamente un evento en el intervalo \((t, t+h]\) está dada por la tasa instantánea en el tiempo \(t\): \[ \mathbb{P}(N(t+h) - N(t) = 1) = \lambda(t) h + o(h) \]
  4. La probabilidad de observar dos o más eventos en dicho intervalo es de orden superior a \(h\): \[ \mathbb{P}(N(t+h) - N(t) \ge 2) = o(h) \]

Una exposición rigurosa sobre los procesos de conteo, sus generalizaciones no homogéneas y sus aplicaciones en sistemas con discontinuidades puede encontrarse en (Ross 1996).

2.1.3 Cadenas de Markov a Tiempo Continuo

Los fallos prolongados en el suministro eléctrico de la red pública alteran estructuralmente la dinámica del sistema. Para modelar estas transiciones entre estados macroscópicos del entorno, introducimos una cadena de Markov en tiempo continuo.

Definición 2.6 (Cadena de Markov a Tiempo Continuo) Sea \(\{\alpha(t)\}_{t \ge 0}\) un proceso estocástico que toma valores en un espacio de estados finito y discreto \(\mathcal{M} = \{1, 2, \dots, m\}\). Se dice que \(\alpha(t)\) es una cadena de Markov en tiempo continuo si para todo \(s, t \ge 0\) y estados \(i, j \in \mathcal{M}\), cumple la propiedad de Markov:

\[ \mathbb{P}(\alpha(t+s) = j \mid \alpha(s) = i, \alpha(u) = \alpha_u, 0 \le u < s) = \mathbb{P}(\alpha(t+s) = j \mid \alpha(s) = i) \]

Las leyes de transición y la evolución temporal de las probabilidades de estado de la cadena \(\{\alpha(t)\}_{t \ge 0}\) se encuentran completamente caracterizadas por la matriz de intensidades de transición \(Q = (q_{ij}) \in \mathbb{R}^{m \times m}\). Si definimos las funciones de probabilidad de transición condicional mediante \(p_{ij}(h) = \mathbb{P}(\alpha(t+h) = j \mid \alpha(t) = i)\) para un incremento temporal positivo \(h > 0\), las componentes de la matriz \(Q\) se determinan evaluando el límite analítico en el origen:

  1. Para transiciones entre estados distintos (\(i \neq j\)), la componente \(q_{ij}\) representa la tasa instantánea o intensidad de conmutación desde el régimen \(i\) hacia el régimen \(j\), definida como:

\[ q_{ij} = \lim_{h \to 0^+} \frac{p_{ij}(h)}{h} \ge 0 \]

  1. Para los elementos situados sobre la diagonal principal (\(i = j\)), la componente \(q_{ii}\) representa la tasa neta de salida del estado \(i\), cumpliendo por conservación de la probabilidad que la suma por filas de la matriz \(Q\) sea idénticamente nula:

\[ q_{ii} = \lim_{h \to 0^+} \frac{p_{ii}(h) - 1}{h} = -\sum_{j \neq i} q_{ij} \]

A través de esta formulación basada en límites, las probabilidades de transición de primer orden quedan descritas mediante las expresiones \(p_{ij}(h) = q_{ij}h + o(h)\) para \(i \neq j\), y \(p_{ii}(h) = 1 + q_{ii}h + o(h)\). Esto permite modelar las conmutaciones macroscópicas de la dinámica del refrigerador sin necesidad de introducir variables temporales discretas ni heurísticas. Los lectores interesados en profundizar en las propiedades asintóticas y de estabilidad de estos procesos híbridos pueden remitirse al texto especializado de (Asmussen 2003).

2.2 Ecuaciones Diferenciales Estocásticas y la Integral de Itô

Una vez establecidos los procesos estocásticos de soporte, es necesario definir las reglas operacionales que permiten construir y resolver ecuaciones sujetas a perturbaciones aleatorias continuas. Dado que las trayectorias del movimiento Browniano no son de variación acotada y tampoco son diferenciables en ningún punto, entonces la expresión clásica \(dW(t)/dt\) no tiene sentido dentro del cálculo ordinario. Por lo tanto, la integración respecto a procesos estocásticos requiere la construcción de una nueva herramienta analítica conocida como la integral de Itô.

Definición 2.7 (Integral de Itô) Sea \(\{X(t)\}_{t \ge 0}\) un proceso estocástico adaptado a la filtración Browniana \(\{\mathcal{F}_t\}_{t \ge 0}\) que satisface la condición de integrabilidad, i.e. \(\mathbb{E}\left[\int_0^T X^2(t) dt\right] < \infty\). La integral de Itô de \(X(t)\) respecto al proceso de Wiener \(W(t)\) se define como el límite en media cuadrática de sumas de Riemann aproximadas por la izquierda:

\[ \int_0^T X(t) dW(t) = \lim_{n \to \infty} \sum_{i=0}^{n-1} X(t_i) [W(t_{i+1}) - W(t_i)] \quad \text{en } L^2 \]

donde \(0 = t_0 < t_1 < \dots < t_n = T\) es una partición del intervalo \([0, T]\) cuyo diámetro tiende a cero cuando \(n \to \infty\).

A diferencia del cálculo clásico, evaluar el integrando estrictamente en el extremo izquierdo de cada subintervalo (\(t_i\)) garantiza que la integral resultante conserve la propiedad de martingala, lo que implica que su esperanza matemática es nula, i.e. \(\mathbb{E}\left[\int_0^T X(t) dW(t)\right] = 0\). A partir de este concepto fundamental, se establece la formulación de una Ecuación Diferencial Estocástica (EDE).

Definición 2.8 (Ecuación Diferencial Estocástica) Una ecuación diferencial estocástica para un proceso \(\{X(t)\}_{t \ge 0}\) es una relación simbólica expresada en su forma diferencial mediante:

\[ dX(t) = b(t, X(t)) dt + \sigma(t, X(t)) dW(t) \tag{2.1}\]

donde \(b(t, X(t))\) denota el coeficiente de deriva y \(\sigma(t, X(t))\) representa el coeficiente de difusión.

El término \(dX(t)\) en la Ecuación 3.1 no debe interpretarse como una derivada ordinaria, sino como una representación abreviada de su ecuación integral equivalente:

\[ X(t) = X(0) + \int_0^t b(s, X(s)) ds + \int_0^t \sigma(s, X(s)) dW(s) \tag{2.2}\]

En la Ecuación 3.2, la primera integral respecto al tiempo es una integral ordinaria de Lebesgue-Stieltjes que captura la tendencia determinista del sistema, mientras que la segunda es una integral de Itô que modela el ruido estocástico continuo. Para una revisión rigurosa del cálculo estocástico elemental, se sugiere consultar a (Karatzas y Shreve 1998).

Para asegurar que una EDE posea una solución única ante cualquier condición inicial, los coeficientes de deriva y difusión deben cumplir ciertas condiciones, expuestas en el siguiente teorema de existencia y unicidad.

Teorema 2.1 (Teorema de Existencia y Unicidad) Sea la EDE definida en la Ecuación 3.1 con una condición inicial \(X(0) = X_0\) independiente del proceso de Wiener. Supóngase que para todo \(t \in [0, T]\) y variables \(x, y \in \mathbb{R}\), los coeficientes satisfacen las siguientes dos restricciones:

  1. Condición de Lipschitz global: Existe una constante \(K > 0\) tal que: \[ |b(t, x) - b(t, y)| + |\sigma(t, x) - \sigma(t, y)| \le K |x - y| \]
  2. Condición de crecimiento lineal: Existe una constante \(C > 0\) tal que: \[ |b(t, x)| + |\sigma(t, x)| \le C (1 + |x|) \]

Bajo el cumplimiento de ambas condiciones, la ecuación tiene una solución fuerte única \(\{X(t)\}_{t \in [0, T]}\) con trayectorias continuas con probabilidad 1, una demostración a detalle de este teorema, basada en el método de aproximaciones sucesivas de Picard, se encuentra en (Arnold 1974)

La condición de Lipschitz previene que las trayectorias colapsen de manera indeterminada, garantizando la unicidad, mientras que la restricción de crecimiento lineal evita que las soluciones diverjan a infinito en un tiempo finito.

2.3 El Proceso de Ornstein-Uhlenbeck Clásico

Como paso previo al desarrollo de nuestro modelo termodinámico final, es indispensable introducir un tipo particular de EDE que modela la inercia física y la atracción hacia un estado de equilibrio: el proceso de Ornstein-Uhlenbeck.

Definición 2.9 (Proceso de Ornstein-Uhlenbeck) Un proceso estocástico \(\{X(t)\}_{t \ge 0}\) es un proceso de Ornstein-Uhlenbeck si satisface la siguiente ecuación diferencial estocástica lineal homogénea:

\[ dX(t) = \kappa (\theta - X(t)) dt + \sigma dW(t) \tag{2.3}\]

donde \(\kappa > 0\) representa la velocidad de reversión a la media, \(\theta \in \mathbb{R}\) denota el nivel de equilibrio de largo plazo y \(\sigma > 0\) es la volatilidad del sistema.

La característica principal de la Ecuación 3.3 radica en su deriva lineal \(b(x) = \kappa(\theta - x)\). Cuando el estado del proceso supera el valor de equilibrio (\(X(t) > \theta\)), la deriva se vuelve negativa, empujando la trayectoria hacia abajo; inversamente, si el proceso se encuentra por debajo del nivel de consigna (\(X(t) < \theta\)), la deriva se vuelve positiva, con lo cual hay un crecimiento hacia el promedio. Esta propiedad de atracción convierte a este proceso en la base ideal para simular la oscilación térmica de sistemas cerrados regidos por la ley de enfriamiento de Newton, cuyas propiedades analíticas detalladas se discuten en (Karlin y Taylor 1998).

2.4 Formulación de la Ecuación Diferencial Estocástica General

Una vez definidos los elementos estocásticos elementales, es posible formular el marco matemático que une la evolución analítica continua con las perturbaciones aleatorias y los saltos discretos. De acuerdo con el marco general desarrollado por (Yin y Zhu 2010) y (Platen y Bruti-Liberati 2010), una Difusión Híbrida con Conmutación de Régimen y Saltos se define mediante el siguiente sistema de ecuaciones diferenciales estocásticas:

\[ dT(t) = \mu(T(t), \alpha(t)) dt + \sigma(T(t), \alpha(t)) dW(t) + \gamma(T(t^-), \alpha(t^-)) dN(t) \tag{2.4}\]

En la Ecuación 2.4, el término \(T(t^-) = \lim_{s \to t^-} T(s)\) preserva la propiedad de continuidad por la izquierda con límites por la derecha (càdlàg) del proceso ante la ocurrencia de un salto. Las funciones de coeficientes se definen como: \[\mu: \mathbb{R} \times \mathcal{M} \to \mathbb{R} \quad \text{(Coeficiente de deriva o tendencia)}\] \[\sigma: \mathbb{R} \times \mathcal{M} \to \mathbb{R} \quad \text{(Coeficiente de difusión o volatilidad)}\] \[\gamma: \mathbb{R} \times \mathcal{M} \to \mathbb{R} \quad \text{(Magnitud o intensidad del impacto del salto)}\]

La incorporación con la cadena de Markov \(\alpha(t)\) indica que los parámetros estructurales del sistema cambian de forma aleatoria e instantánea cuando el entorno conmuta de estado.

Para ilustrar el impacto de nuestra formulación matemática sobre el modelado físico de la red de frío, es fundamental contrastar el comportamiento de las trayectorias resultantes. La simulación numérica del modelo revela cómo la incorporación de discontinuidades captura fenómenos que los modelos clásicos omiten.

Como muestra la Figura 2.3, al modelar el sistema exclusivamente con componentes difusivos continuos se subestima el riesgo de trayectorias térmicas fuera del rango normativo de la OMS (2 °C a 8 °C). La inclusión del proceso de saltos justifica nuestra necesidad de utilizar el Lema de Itô generalizado, ya que la temperatura experimenta cambios finitos instantáneos que rompen la diferenciabilidad clásica del modelo.

2.5 El Modelo Estocástico de Red de Frío (Ornstein-Uhlenbeck Modificado)

Pasando a la física de nuestro problema particular, adaptamos la Ecuación 2.4 bajo una estructura termodinámica de reversión a la media. Trabajaremos bajo la hipótesis de que el comportamiento de la temperatura interna \(T(t)\) de un refrigerador institucional de vacunas se rige por la siguiente ecuación diferencial estocástica de Ornstein-Uhlenbeck híbrida con saltos de Poisson:

\[ dT(t) = \kappa(\alpha(t)) [\theta(\alpha(t)) - T(t)] dt + \sigma(\alpha(t)) dW(t) + \gamma dN(t) \tag{2.5}\]

Bajo esta parametrización particular, el espacio de estados de la cadena de Markov se restringe a dos regímenes operativos fundamentales, \(\mathcal{M} = \{1, 2\}\), cuyas implicaciones físicas y estocásticas se detallan en los siguientes conceptos:

Definición 2.10 (Inercia Térmica y Parámetros Estructurales) La inercia térmica es la capacidad de la masa interna del refrigerador (biológicos, paquetes refrigerantes y botellas de agua) para amortiguar la transferencia de calor del exterior. En la Ecuación 2.5, se modela mediante el coeficiente de velocidad de reversión \(\kappa(\alpha(t)) > 0\). A mayor inercia térmica, menor será el valor de \(\kappa\) en ausencia de energía eléctrica, retrasando el calentamiento del refrigerador. El parámetro de volatilidad \(\sigma(\alpha(t)) > 0\) mide el ruido continuo gaussiano inducido por el ciclo del compresor.

Definición 2.11 (Corte de Energía (Conmutación de Régimen)) Se define como la transición de la cadena de Markov debido a fallos en el suministro eléctrico. El sistema conmuta del régimen con suministro normal (\(\alpha(t) = 1\)) al régimen de falla (\(\alpha(t) = 2\)). Esta conmutación altera los límites asintóticos de la deriva en la Ecuación 2.5:

  1. Régimen \(\alpha(t) = 1\): El sistema converge a la temperatura ideal del termostato, es decir, \(\theta(1) = 4^\circ\text{C}\).
  2. Régimen \(\alpha(t) = 2\): Al apagarse el motor, el sistema interrumpe el enfriamiento y la temperatura interna comienza a subir hacia la temperatura ambiente exterior del centro de salud, parametrizada por \(\theta(2) = T_{\text{amb}}\).

Definición 2.12 (Apertura de Puertas (Perturbaciones por Saltos)) Corresponde a la entrada brusca de aire cálido exterior provocada por la manipulación operativa del personal de enfermería. Este fenómeno ocurre de forma intermitente y se modela en la Ecuación 2.5 mediante el término de saltos \(\gamma dN(t)\), donde \(\gamma > 0\) representa el incremento térmico discreto e instantáneo en grados Celsius cada vez que el diferencial del proceso de Poisson registra un evento (\(dN(t) = 1\)).

2.6 El Lema de Itô Clásico y Generalizado

Para realizar transformaciones algebraicas sobre funciones que dependen de procesos estocásticos o para desarrollar algoritmos de aproximación computacional válidos, el teorema fundamental del cálculo determinista debe sustituirse por el Lema de Itô. Introducimos inicialmente la versión elemental para difusiones continuas.

Teorema 2.2 (Lema de Itô para Difusiones Continuas) Sea \(\{X(t)\}_{t \ge 0}\), considere la EDE dada por la Ecuación 3.1, con condición inicial \(X(0) = x_0\),, y sea \(V(t, x)\) una función escalar continuamente diferenciable en su componente temporal \(t\) y dos veces continuamente diferenciable en su componente espacial \(x\). El diferencial estocástico de la función compuesta viene dado por:

\[ dV(t, X(t)) = \left[ \frac{\partial V}{\partial t} + b(t, X(t))\frac{\partial V}{\partial x} + \frac{1}{2}\sigma^2(t, X(t))\frac{\partial^2 V}{\partial x^2} \right] dt + \sigma(t, X(t))\frac{\partial V}{\partial x} dW(t) \]

El término de segundo orden respecto a la derivada espacial surge de la propiedad cuadrática del movimiento Browniano, donde \((dW(t))^2 \to dt\) en un sentido probabilístico. Este desarrollo elemental se detalla conceptualmente en (Karatzas y Shreve 1998).

No obstante, dado que nuestro modelo usa conmutaciones estructurales discretas y discontinuidades puntuales, la versión continua resulta insuficiente. Apoyados en los desarrollos de (Yin y Zhu 2010) y (Platen y Bruti-Liberati 2010), establecemos el siguiente teorema analítico que rige el cálculo sobre trayectorias discontinuas con conmutación:

Teorema 2.3 (Fórmula de Itô para Difusiones Híbridas con Saltos) Sea \(V(t, T, i)\) una función continuamente diferenciable en su componente temporal \(t\), y dos veces continuamente diferenciable en su componente espacial \(T\) para cada régimen operativo \(i \in \mathcal{M}\). Si \(T(t)\) es un proceso que satisface la Ecuación 2.4, entonces el diferencial estocástico de la función compuesta \(V(t, T(t), \alpha(t))\) viene dado por:

\[ \begin{aligned} dV(t, T(t), \alpha(t)) = & \left[ \frac{\partial V}{\partial t} + \frac{\partial V}{\partial T}\mu(T, \alpha) + \frac{1}{2}\frac{\partial^2 V}{\partial T^2}\sigma^2(T, \alpha) + \sum_{j \in \mathcal{M}} q_{\alpha(t)j}V(t, T, j) \right] dt \\ & + \frac{\partial V}{\partial T}\sigma(T, \alpha) dW(t) + \left[ V(t, T(t^-) + \gamma, \alpha(t^-)) - V(t, T(t^-), \alpha(t^-)) \right] dN(t) \end{aligned} \tag{2.6}\]

Como se puede apreciar en el Teorema 2.3, el operador diferencial de Itô se logra expandir. El primer término entre corchetes añade a la derivada temporal y al generador de difusión clásico una sumatoria ponderada por las tasas de transición \(q_{ij}\) de la matriz \(Q\), lo cual captura el efecto del cambio en la deriva. Por su parte, la componente final sustituye la derivada espacial tradicional por un operador de diferencias finitas encargado de absorber la discontinuidad en los tiempos de salto del proceso de Poisson.

2.7 Soluciones Numéricas de Ecuaciones Diferenciales Estocásticas

En la práctica, la gran mayoría de las ecuaciones diferenciales estocásticas carecen de una solución analítica explícita debido a la no linealidad de sus coeficientes o al acoplamiento de sus perturbaciones. Por este motivo, resulta necesario recurrir a esquemas de aproximación numérica distribuidos en un mallado temporal discreto. A diferencia del cálculo determinista, donde la convergencia se evalúa de forma puntual, en el ámbito estocástico la cercanía entre la solución real \(X(t)\) y la aproximación discreta \(Y_n\) requiere criterios fundamentados en la teoría de la medida.

Para definir los criterios de convergencia, consideremos una partición regular del intervalo de tiempo \([0, T]\) con un tamaño de paso constante \(\Delta t = \frac{T}{N}\), fijando los nodos temporales como \(t_n = n \Delta t\) para cada paso \(n = 0, 1, \dots, N\). Denotaremos a la solución aproximada en el nodo \(t_n\) como \(Y_n = Y(t_n)\).

Definición 2.13 (Convergencia Fuerte) Se dice que una aproximación discreta \(Y\) converge fuertemente de orden \(\gamma > 0\) hacia la solución real \(X(T)\) en el tiempo terminal \(T\) si existe una constante positiva \(C\), independiente de \(\Delta t\), tal que se cumple la desigualdad:

\[ \mathbb{E}\left[|X(T) - Y_N|\right] \le C (\Delta t)^\gamma \]

La convergencia fuerte evalúa el error promedio directo sobre cada trayectoria individual del proceso. Es el criterio adecuado cuando interesa simular caminos muestrales específicos del sistema.

Definición 2.14 (Convergencia Débil) Se dice que una aproximación discreta \(Y\) converge débilmente de orden \(\beta > 0\) hacia la solución real \(X(T)\) en el tiempo terminal \(T\) si, para toda función de prueba \(g: \mathbb{R} \to \mathbb{R}\) continuamente diferenciable de crecimiento polinomial, existe una constante positiva \(C\) tal que:

\[ |\mathbb{E}[g(X(T))] - \mathbb{E}[g(Y_N)]| \le C (\Delta t)^\beta \]

La convergencia débil no compara trayectoria por trayectoria, sino que evalúa la aproximación de la distribución de probabilidad global y sus momentos estadísticos (como la media y la varianza), para más detalles consultar a (Kloeden y Platen 1992).

2.7.1 Esquema Numérico de Euler-Maruyama

El método de Euler-Maruyama constituye la extensión estocástica más elemental del método de Euler para ecuaciones diferenciales ordinarias. Este esquema aproxima el cambio continuo truncando las integrales de la ecuación mediante aproximaciones de orden inferior.

Teorema 2.4 (Teorema de Convergencia de Euler-Maruyama) Sea \(\{X(t)\}_{t \ge 0}\), considere la EDE dada por la Ecuación 3.1, con condición inicial \(X(0) = x_0\), si se cumplen las hipotesis del teorema de existencia y unicidad Teorema 3.3 y los coeficientes \(b\) y de difusión \(\sigma\) son continuamente diferenciables, entonces el esquema de Euler-Maruyama converge fuertemente con orden:

\[ \gamma = 0.5 \]

y converge débilmente con un orden de acotación de \(\beta = 1.0\).

Este orden de convergencia se fundamenta en que el incremento del movimiento Browniano domina algebraicamente sobre el incremento del tiempo determinista, dado que su escala de variación es proporcional a \(\sqrt{\Delta t}\), la demostración de este teorema se encuentra en (Kloeden y Platen 1992).

Algoritmo General de Euler-Maruyama

Para aproximar numéricamente las trayectorias de la ecuación en el intervalo \([0, T]\) con condición inicial \(X(0) = x_0\):

  1. Inicialización:
    • Fijar el número de pasos \(N\) y calcular el incremento \(\Delta t = T/N\).
    • Construir la malla temporal \(t_n = n \Delta t\) para \(n = 0, 1, \dots, N\).
    • Asignar el valor inicial a la primera posición del vector: \(Y_0 = x_0\).
  2. Bucle de Simulación: Para cada paso temporal \(n = 0, 1, \dots, N-1\):
    • Generar una variable aleatoria normal estándar independiente: \(Z_n \sim \mathcal{N}(0, 1)\).
    • Calcular el incremento del proceso de Wiener mediante el escalamiento: \[\Delta W_n = W(t_{n+1}) - W(t_n) = Z_n \sqrt{\Delta t}\]
    • Actualizar el estado del proceso en el siguiente nodo evaluando la relación recursiva: \[Y_{n+1} = Y_n + b(t_n, Y_n) \Delta t + \sigma(t_n, Y_n) \Delta W_n\]
  3. Resultado: El vector de estados discreto \(\{Y_0, Y_1, \dots, Y_N\}\) representa la trayectoria simulada aproximada del proceso.

2.7.2 Esquema Numérico de Milstein

El método de Milstein es un esquema numérico avanzado de orden superior que corrige la aproximación de la componente difusiva. Surge de aplicar de manera explícita el Lema de Itô al integrando de la componente estocástica en la expansión de Taylor-Itô, rescatando los términos de segundo orden que el método de Euler-Maruyama ignora.

Teorema 2.5 (Teorema de Convergencia de Milstein) Sea \(\{X(t)\}_{t \ge 0}\), considere la EDE dada por la Ecuación 3.1 sujeta a las condiciones estándar de regularidad, es decir si los coeficientes \(b(t, x)\) y \(\sigma(t, x)\) son dos veces continuamente diferenciables respecto a sus componentes y cumplen los criterios de crecimiento acotado, entonces el esquema numérico de Milstein converge fuertemente con un orden superior dado por:

\[ \gamma = 1.0 \]

El incremento en la velocidad de convergencia fuerte se logra al incorporar de forma analítica el término correspondiente a la integral estocástica iterada

\[ \int_{t_n}^{t_{n+1}} \int_{t_n}^s dW(u) dW(s) = \frac{1}{2} \left[ (\Delta W_n)^2 - \Delta t \right], \]

la cual modela la curvatura interna del ruido estocástico dentro del intervalo de simulación, lo que permite una aproximación más precisa de la trayectoria. La demostración de este resultado se encuentra en (Kloeden y Platen 1992).

Algoritmo General de Milstein

Para aproximar numéricamente las trayectorias bajo el refinamiento de segundo orden estocástico en el intervalo \([0, T]\) con condición inicial \(X(0) = x_0\):

  1. Inicialización:
    • Establecer el número de intervalos \(N\) y calcular el paso \(\Delta t = T/N\).
    • Definir los puntos de la malla \(t_n = n \Delta t\) para \(n = 0, 1, \dots, N\).
    • Asignar la condición de inicio del proceso: \(Y_0 = x_0\).
  2. Bucle de Simulación: Para cada paso temporal \(n = 0, 1, \dots, N-1\):
    • Obtener una realización independiente de una variable normal estándar: \(Z_n \sim \mathcal{N}(0, 1)\).
    • Establecer el incremento browniano escalar correspondientemente: \(\Delta W_n = Z_n \sqrt{\Delta t}\).
    • Calcular analíticamente el valor de la primera derivada parcial del coeficiente de difusión respecto a la variable espacial evaluado en el punto actual: \[\sigma'(t_n, Y_n) = \frac{\partial \sigma(t, x)}{\partial x} \bigg|_{(t_n, Y_n)}\]
    • Realizar la actualización recursiva del estado integrando la corrección de segundo orden: \[Y_{n+1} = Y_n + b(t_n, Y_n)\Delta t + \sigma(t_n, Y_n)\Delta W_n + \frac{1}{2}\sigma(t_n, Y_n)\sigma'(t_n, Y_n)\left[(\Delta W_n)^2 - \Delta t\right]\]
  3. Resultado: El conjunto ordenado de aproximaciones numéricas \(\{Y_0, Y_1, \dots, Y_N\}\) conforma la trayectoria analizada bajo estabilidad de orden superior.

2.8 Análisis Comparativo de Convergencia Fuerte

Para mostrar la diferencia analítica que hay entre los esquemas de Euler-Maruyama y Milstein, y justificar la necesidad de utilizar este último cuando se requiere precisión en trayectorias individuales, planteamos un problema de control numérico. Consideremos el Movimiento Browniano Geométrico (GBM), una EDE lineal homogénea caracterizada por un coeficiente de difusión multiplicativo, dada por la ecuación:

\[ dX(t) = \mu X(t) dt + \sigma X(t) dW(t) \tag{2.7}\]

con condición inicial \(X(0) = X_0\), tendencia determinista \(\mu > 0\) y volatilidad \(\sigma > 0\). Este proceso posee una solución analítica única dada por:

\[ X(t) = X_0 \exp\left[\left(\mu - \frac{1}{2}\sigma^2\right)t + \sigma W(t)\right] \]

Esta forma cerrada nos permite contrastar directamente las aproximaciones numéricas contra la realidad del proceso. La principal limitación del método de Euler-Maruyama radica en su coeficiente de difusión constante en cada paso temporal. Al truncar la integral estocástica con un orden de convergencia fuerte de 0.5, el esquema no absorbe correctamente la curvatura del ruido multiplicativo (\(\sigma X_t\)), acumulando errores significativos sobre las trayectorias individuales, incluso ante mallados temporales relativamente pequeños. Por el contrario, el método de Milstein integra el término de segundo orden estocástico, logrando que el vector de estados discreto coincida con mayor precisión con la dinámica real del proceso (Kloeden y Platen 1992).

En la Figura 2.4, simulamos una trayectoria de GBM en un horizonte temporal acotado (\(T=2.0\) años) con una volatilidad alta (\(\sigma = 1\)) y un tamaño de paso discreto relativamente grueso (\(\Delta t = 0.05\), correspondiente a \(N=40\) pasos). Esta configuración es deliberada para resaltar las fallas de los aproximadores.

Como se puede apreciar en la Figura 2.4, la trayectoria roja que correspondiente al método de Euler-Maruyama falla en aproximar la dinámica exacta (línea negra), presentando oscilaciones exageradas y alejándose del valor real a medida que el tiempo avanza. Por otro lado, la trayectoria azul del método de Milstein sigue prácticamente de forma idéntica la trayectoria real. Esta diferencia justifica nuestra decisión de utilizar el esquema numérico de Milstein para simular el comportamiento térmico del refrigerador HBC-150, ya que el modelo híbrido presenta un coeficiente de ruido continuo \(\sigma(\alpha(t))\), lo cual genera perturbaciones multiplicativas que requieren un orden de convergencia estricto para no subestimar el riesgo de trayectorias erráticas.

3 DEMOSTRACION DEL TEOREMA

En este capítulo se presentarán las bases conceptuales y el marco formal del cálculo estocástico que fundamentan el desarrollo de nuestro modelo matemático para la red de frío. Se definirán en primer lugar los procesos estocásticos elementales para, posteriormente, formalizar la teoría de medidas aleatorias de salto y construir la ecuación diferencial estocástica (EDE) híbrida que rige el sistema.

3.1 Espacios de Probabilidad, Filtraciones y Procesos Estocásticos

El modelado térmico de un refrigerador de vacunas expuesto a incertidumbres continuas y perturbaciones discretas requiere herramientas más allá del cálculo determinista. Desde una perspectiva analítica, un proceso estocástico representa la generalización de una variable aleatoria indexada en un conjunto ordenado, parametrizando la evolución de un sistema bajo incertidumbre.

Para dotar de rigor a la evolución temporal de la información del sistema, definimos formalmente el entorno probabilístico sobre el cual operan nuestros procesos.

Definición 3.1 (Espacio de Probabilidad Filtrado) Sea \((\Omega, \mathcal{F}, \mathbb{P})\) un espacio de probabilidad completo. Una filtración es una familia no decreciente de sub-\(\sigma\)-álgebras \(\{\mathcal{F}_t\}_{t \ge 0}\) de \(\mathcal{F}\), tal que \(\mathcal{F}_s \subseteq \mathcal{F}_t \subseteq \mathcal{F}\) para todo \(0 \le s \le t\). La cuaterna \((\Omega, \mathcal{F}, \{\mathcal{F}_t\}_{t \ge 0}, \mathbb{P})\) se denomina espacio de probabilidad filtrado. Se asume que la filtración satisface las condiciones habituales: 1. \(\mathcal{F}_0\) contiene todos los conjuntos \(\mathbb{P}\)-nulos de \(\mathcal{F}\). 2. La filtración es continua por la derecha, es decir, \(\mathcal{F}_t = \bigcap_{\varepsilon > 0} \mathcal{F}_{t+\varepsilon}\).

Intuitivamente, la \(\sigma\)-álgebra \(\mathcal{F}_t\) representa todo el historial de información observable del sistema físico hasta el instante \(t\).

Definición 3.2 (Proceso Estocástico) Sea un espacio muestral \(\mathcal{S} \subseteq \mathbb{R}^d\) dotado de su respectiva \(\sigma\)-álgebra de Borel \(\mathcal{B}(\mathcal{S})\). Un proceso estocástico es una familia de variables aleatorias \(\{X_t\}_{t \in \mathcal{T}}\) parametrizadas por \(t \in \mathcal{T}\), donde \(\mathcal{T} \subseteq \mathbb{R}\). Formalmente, es una función medible \(X: \mathcal{T} \times \Omega \to \mathcal{S}\).

Dependiendo de cómo es el conjunto de índices \(\mathcal{T}\), los procesos estocásticos se clasifican en dos:

  1. Procesos estocásticos a tiempo discreto: Si \(\mathcal{T}\) es numerable, por lo general \(\mathcal{T} = \mathbb{N}_0 = \{0, 1, 2, \dots\}\) o \(\mathcal{T} = \mathbb{Z}\), decimos que el proceso estocástico es a tiempo discreto. En este escenario, el sistema evoluciona mediante transiciones discretas en pasos fijos discretizados.
  2. Procesos estocásticos a tiempo continuo: Si \(\mathcal{T}\) es un intervalo de \(\mathbb{R}\), por lo general \(\mathcal{T} = [0, \infty)\) o un intervalo acotado \(\mathcal{T} = [0, T]\), con \(T > 0\), se dice que el proceso estocástico es a tiempo continuo. Esta estructura es la adecuada para modelar fenómenos físicos continuos, como la transferencia térmica.

Para enlazar la teoría probabilística con la observación empírica de un fenómeno, es indispensable establecer la distinción entre el espacio funcional del proceso y sus realizaciones particulares.

Definición 3.3 (Trayectorias del Proceso Estocástico) Si \(\{X_t\}_{t \geq 0}\) es un proceso estocástico a tiempo continuo, para cada \(\omega \in \Omega\) fijo y \(\mathcal{S} = \mathbb{R}\), se definen las trayectorias (o caminos muestrales) del proceso como la aplicación topológica: \[t \mapsto X_t(\omega), \quad t \in [0, \infty).\]

Para la formulación de integrales estocásticas, el proceso debe respetar la temporalidad de la información, lo cual se formaliza mediante la adaptabilidad.

Definición 3.4 (Proceso Adaptado y Espacio Càdlàg) Un proceso estocástico \(\{X_t\}_{t \ge 0}\) es adaptado a la filtración \(\{\mathcal{F}_t\}_{t \ge 0}\) si, para cada \(t \ge 0\), la variable aleatoria \(X_t\) es \(\mathcal{F}_t\)-medible. Adicionalmente, decimos que el proceso pertenece al espacio càdlàg (del francés continu à droite, limite à gauche) si sus trayectorias \(t \mapsto X_t(\omega)\) son continuas por la derecha y poseen límites finitos por la izquierda para casi todo \(\omega \in \Omega\).

La propiedad càdlàg es un requisito analítico ineludible en nuestra investigación, puesto que las perturbaciones de la red de frío por aperturas de puerta inducen discontinuidades instantáneas (saltos) en la temperatura.

Finalmente, para evaluar eventos que ocurren en tiempos aleatorios (como fallas de energía de la CFE), requerimos la siguiente definición:

Definición 3.5 (Tiempo de Parada (Stopping Time)) Una variable aleatoria \(\tau: \Omega \to [0, \infty]\) es un tiempo de parada respecto a la filtración \(\{\mathcal{F}_t\}_{t \ge 0}\) si para todo \(t \ge 0\), el evento de que el tiempo ocurra antes o en el instante \(t\) depende únicamente de la información disponible hasta ese instante; matemáticamente: \(\{\omega \in \Omega : \tau(\omega) \le t\} \in \mathcal{F}_t\).

3.2 Componentes Estocásticos Fundamentales

Las propiedades analíticas de un proceso estocástico se definen estrictamente a partir del comportamiento de sus componentes (Karlin y Taylor 1998). Los componentes aleatorios de nuestro sistema se sustentan en una clase específica de procesos equilibrados.

Definición 3.6 (Martingala) Un proceso estocástico a tiempo continuo \(\{M_t\}_{t \ge 0}\) integrable (i.e., \(\mathbb{E}[\vert{}M_t\vert{}] < \infty\) para todo \(t\)) y adaptado a \(\{\mathcal{F}_t\}_{t \ge 0}\), es una martingala si cumple la propiedad de valor esperado condicional nulo para incrementos futuros: \[\mathbb{E}[M_t \mid \mathcal{F}_s] = M_s, \quad \text{casi seguramente para todo } 0 \le s \le t.\]

La martingala representa matemáticamente un “juego justo” sin tendencia predictible. Esta propiedad es el pilar para construir integrales estocásticas no sesgadas.

3.2.1 Movimiento Browniano (Proceso de Wiener)

Para representar las fluctuaciones térmicas continuas de baja intensidad asociadas al ruido intrínseco del termostato y microtransferencias de calor, se utiliza el movimiento Browniano.

Definición 3.7 (Proceso de Wiener) Un proceso estocástico a tiempo continuo \(\{W(t)\}_{t \ge 0}\) definido sobre un espacio de probabilidad filtrado \((\Omega, \mathcal{F}, \{\mathcal{F}_t\}, \mathbb{P})\) es un movimiento Browniano estándar o proceso de Wiener si cumple con las siguientes propiedades:

  1. \(W(0) = 0\) con probabilidad 1.
  2. Posee incrementos independientes; es decir, para cualesquiera tiempos \(0 \le t_1 < t_2 < \dots < t_n\), las variables aleatorias \(W(t_2)-W(t_1), \dots, W(t_n)-W(t_{n-1})\) son mutuamente independientes y son independientes de la \(\sigma\)-álgebra \(\mathcal{F}_{t_1}\).
  3. Posee incrementos estacionarios gaussianos: para todo \(t > s \ge 0\), \(W(t) - W(s) \sim \mathcal{N}(0, t-s)\).
  4. Es una martingala respecto a la filtración \(\{\mathcal{F}_t\}_{t \ge 0}\).

El término \(dW(t) = W(t+dt) - W(t)\) representa el diferencial del proceso de Wiener. Este denota una perturbación gaussiana elemental en un intervalo infinitesimal \(dt\), caracterizada por una media \(\mathbb{E}[dW(t)] = 0\) y una varianza \(\mathbb{E}[(dW(t))^2] = dt\). Un rasgo crítico del movimiento Browniano es que, aunque sus trayectorias son continuas, son diferenciables en ningún punto con probabilidad 1. Para una revisión detallada de estas construcciones analíticas, se sugiere consultar a (Karatzas y Shreve 1998).

3.2.2 Procesos de Poisson y Saltos

Las aperturas de las puertas del refrigerador por el personal médico constituyen eventos discretos y repentinos que alteran instantáneamente la temperatura interna. Este fenómeno pertenece a la clase de procesos de saltos puros.

Definición 3.8 (Proceso de Poisson Homogéneo) Un proceso estocástico a tiempo continuo \(\{N(t)\}_{t \ge 0}\) que toma valores enteros en \(\mathbb{N}_0\) es un proceso de Poisson homogéneo con parámetro de intensidad constante \(\lambda > 0\) si:

  1. \(N(0) = 0\) con probabilidad 1.
  2. Posee incrementos independientes.
  3. Posee incrementos estacionarios. La variable aleatoria \(N(t)\) sigue una distribución de Poisson con parámetro \(\lambda t\): \[\mathbb{P}(N(t) = n) = \frac{(\lambda t)^n e^{-\lambda t}}{n!}, \quad n = 0, 1, 2, \dots\]

Las probabilidades de transición en un intervalo acotado \(h > 0\) se especifican rigurosamente mediante el límite asintótico cuando \(h \to 0\): \[\mathbb{P}(N(t+h) - N(t) = 1) = \lambda h + o(h), \quad \mathbb{P}(N(t+h) - N(t) \ge 2) = o(h)\]

Sin embargo, en la dinámica real de un centro de salud, la tasa de aperturas del refrigerador no es constante; exhibe una estacionalidad diaria.

Definición 3.9 (Proceso de Poisson No Homogéneo) Un proceso estocástico a tiempo continuo \(\{N(t)\}_{t \ge 0}\) es un proceso de Poisson no homogéneo con función de intensidad localmente integrable \(\lambda(t) \ge 0\) si sus incrementos son independientes y para todo \(t \ge 0\) y \(h > 0\): \[\mathbb{P}(N(t+h) - N(t) = 1) = \lambda(t) h + o(h)\]

Para acoplar la magnitud física del calor que ingresa en cada apertura, definimos la composición del proceso de conteo con magnitudes aleatorias.

Definición 3.10 (Proceso de Poisson Compuesto) Sea \(\{N(t)\}_{t \ge 0}\) un proceso de Poisson con función de intensidad \(\lambda(t)\), y sea \(\{\gamma_i\}_{i \ge 1}\) una sucesión de variables aleatorias independientes e idénticamente distribuidas, independientes de \(N(t)\). El proceso de Poisson compuesto \(J(t)\) se define como: \[J(t) = \sum_{i=1}^{N(t)} \gamma_i\]

Para una exposición rigurosa sobre los procesos de conteo y sus aplicaciones en sistemas con discontinuidades, consúltese (Ross 1996).

3.2.3 Cadenas de Markov a Tiempo Continuo

Para modelar los fallos prolongados en el suministro eléctrico de la red pública, introducimos una cadena de Markov.

Definición 3.11 (Cadena de Markov a Tiempo Continuo) Sea \(\{\alpha(t)\}_{t \ge 0}\) un proceso estocástico que toma valores en un espacio de estados finito y discreto \(\mathcal{M} = \{1, 2, \dots, m\}\). Se dice que \(\alpha(t)\) es una cadena de Markov en tiempo continuo si cumple la propiedad de Markov: \[\mathbb{P}(\alpha(t+s) = j \mid \alpha(s) = i, \mathcal{F}_s) = \mathbb{P}(\alpha(t+s) = j \mid \alpha(s) = i)\]

La evolución temporal se caracteriza por la matriz generadora de intensidades de transición \(Q = (q_{ij}) \in \mathbb{R}^{m \times m}\), donde las tasas de conmutación desde el régimen \(i\) hacia el régimen \(j\) están dadas por \(p_{ij}(h) = q_{ij}h + o(h)\) para \(i \neq j\). Por conservación de probabilidad, las entradas diagonales satisfacen \(q_{ii} = -\sum_{j \neq i} q_{ij}\). Los detalles asintóticos de estos procesos híbridos se discuten en (Asmussen 2003).

3.3 Teoría de Medidas Aleatorias y Saltos Estocásticos

En el modelado estocástico riguroso, la representación de perturbaciones por saltos (como el diferencial \(dJ(t)\) de un proceso de Poisson compuesto) requiere la formalización mediante teoría de la medida. Esto es estrictamente necesario para poder aplicar teoremas de existencia y unicidad avanzados (situ2005theory?).

Definición 3.12 (Medida Aleatoria de Conteo de Poisson) Sea un espacio medible de “marcas” \((\mathcal{Z}, \mathcal{B}(\mathcal{Z}))\), donde \(\mathcal{Z} \subseteq \mathbb{R}\). Una medida aleatoria de Poisson \(N(dt, dz)\) sobre \([0, \infty) \times \mathcal{Z}\) se define de manera que, para cualquier intervalo de tiempo \((s, t]\) y subconjunto espacial \(A \in \mathcal{B}(\mathcal{Z})\), la integral evaluada \(N((s,t] \times A) = \int_s^t \int_A N(du, dz)\) cuenta exactamente el número de saltos que ocurrieron en el intervalo de tiempo \((s, t]\) cuya magnitud métrica (marca) perteneció al conjunto \(A\).

Para que el modelo sea manejable analíticamente, debe extraerse la esperanza matemática de estos saltos.

Definición 3.13 (Medida de Intensidad (Medida de Lévy)) La esperanza de la medida de conteo se denota por la medida producto \(\nu(dt, dz) = \mathbb{E}[N(dt, dz)]\). Si el proceso de saltos es generado por un proceso de Poisson no homogéneo con tasa \(\lambda(t)\) y los tamaños de salto tienen una distribución de probabilidad espacial \(F(z)\), la medida de intensidad se factoriza analíticamente como: \[\nu(dt, dz) = \lambda(t) dF(z) dt\] donde \(\nu(dz) = \lambda(t) dF(z)\) se conoce como la medida de Lévy o compensador determinista del salto espacial.

Debido a que la medida de conteo \(N(dt, dz)\) acumula valores monótonamente crecientes, su esperanza matemática no es nula, lo que impide utilizarla directamente para construir integrales de martingala (como sí lo permite el diferencial Browniano \(dW(t)\)). Para solucionar esto, el cálculo estocástico define la medida centrada.

Definición 3.14 (Medida de Poisson Compensada) Se define la medida aleatoria de Poisson compensada \(\tilde{N}(dt, dz)\) como la diferencia algebraica entre la medida empírica observada y su intensidad esperada: \[\tilde{N}(dt, dz) = N(dt, dz) - \nu(dz) dt\] Por definición estricta de la esperanza condicional, el proceso \(M_t = \int_0^t \int_A \tilde{N}(ds, dz)\) constituye una verdadera martingala respecto a la filtración \(\{\mathcal{F}_t\}_{t \ge 0}\), con \(\mathbb{E}[M_t] = 0\).

Con este herramental analítico, es posible enunciar un lema de equivalencia que resulta ser la “piedra angular” para validar la inclusión del Proceso de Poisson Compuesto dentro del marco del análisis estocástico general con medidas de salto.

Lema 3.1 (Lema de Equivalencia del Proceso de Poisson Compuesto) Sea \(J(t) = \sum_{i=1}^{N(t)} \gamma_i\) un proceso de Poisson compuesto con función de intensidad de eventos \(\lambda(t)\) y magnitudes de salto independientes \(\gamma_i\) distribuidas mediante una medida de densidad empírica \(dF(z)\). El diferencial estocástico puro de dicho proceso admite la siguiente equivalencia en teoría de medidas: \[dJ(t) = \int_{\mathbb{R}} z N(dt, dz)\] Consecuentemente, mediante la inserción de la medida de Lévy \(\nu(dz)dt = \lambda(t)dF(z)dt\), el diferencial puede descomponerse analíticamente en una martingala de salto compensado y una deriva de arrastre determinista: \[dJ(t) = \int_{\mathbb{R}} z \tilde{N}(dt, dz) + \left( \lambda(t) \int_{\mathbb{R}} z dF(z) \right) dt\] Lo que es equivalente a afirmar que el salto total se separa en ruido estocástico purificado y un valor esperado incondicional dado por \(\left( \lambda(t) \mathbb{E}[\gamma_i] \right) dt\).

Esta equivalencia (@lem-equivalencia-saltos) nos permitirá, en secciones posteriores, transformar la EDE fenomenológica de la red de frío en una ecuación equivalente estandarizada para evaluar formalmente sus condiciones de existencia y unicidad apoyándonos en los postulados rigurosos de R. Situ (situ2005theory?).

3.4 Teoría de Integración Estocástica

Para dotar de significado analítico a las perturbaciones aleatorias, es imperativo establecer un marco riguroso de integración. Dado que el movimiento Browniano es de variación cuadrática no nula y no diferenciable, la integral de Riemann-Stieltjes es inaplicable. De manera análoga, la integración respecto a las medidas de salto requiere fundamentos en la teoría de martingalas de cuadrado integrable.

3.4.1 Integración respecto al Movimiento Browniano

Sea \(\mathcal{L}^2(0, T)\) el espacio de los procesos estocásticos \(\{X(t)\}_{t \ge 0}\) que son adaptados a la filtración \(\{\mathcal{F}_t\}_{t \ge 0}\), progresivamente medibles, y que satisfacen la condición de integrabilidad estricta \(\mathbb{E}\left[\int_0^T X^2(t) dt\right] < \infty\).

Definición 3.15 (Integral de Itô) Sea \(\{X(t)\}_{t \ge 0} \in \mathcal{L}^2(0, T)\). La integral de Itô de \(X(t)\) respecto al proceso de Wiener \(W(t)\) se define como el límite en media cuadrática (\(L^2\)) de sumas de Riemann aproximadas estrictamente por la izquierda:

\[ \int_0^T X(t) dW(t) = \lim_{n \to \infty} \sum_{i=0}^{n-1} X(t_i) [W(t_{i+1}) - W(t_i)] \quad \text{en } L^2(\Omega, \mathbb{P}) \]

donde \(0 = t_0 < t_1 < \dots < t_n = T\) es una partición del intervalo \([0, T]\) cuyo diámetro tiende a cero cuando \(n \to \infty\).

Al evaluar el integrando en el extremo izquierdo de cada subintervalo, la integral resultante hereda la propiedad de martingala del movimiento Browniano, garantizando que \(\mathbb{E}\left[\int_0^T X(t) dW(t)\right] = 0\). Esta construcción nos provee de una de las herramientas de acotación más poderosas del cálculo estocástico.

Teorema 3.1 (Isometría de Itô) Para cualquier proceso \(\{X(t)\}_{t \ge 0} \in \mathcal{L}^2(0, T)\), la varianza de la integral estocástica es exactamente igual a la esperanza de la integral determinista del proceso al cuadrado respecto al tiempo de Lebesgue:

\[ \mathbb{E}\left[ \left( \int_0^T X(t) dW(t) \right)^2 \right] = \mathbb{E}\left[ \int_0^T X^2(t) dt \right] \]

La demostración de esta isometría descansa en la independencia de los incrementos de \(W(t)\) y es un pilar para demostrar la unicidad de soluciones en ecuaciones estocásticas (Karatzas y Shreve 1998).

3.4.2 Integración Estocástica respecto a Medidas de Salto

Para modelar la acumulación de energía o masa proveniente de eventos discretos, definimos la integral respecto a la medida aleatoria de Poisson compensada \(\tilde{N}(dt, dz)\), la cual fue definida formalmente en la sección anterior.

Definición 3.16 (Integral Estocástica con Saltos) Sea \(H(t, z, \omega)\) un proceso predecible respecto a \(\mathcal{F}_t\), tal que \(\mathbb{E} \left[ \int_0^T \int_{\mathbb{R}} |H(t, z)|^2 \nu(dz) dt \right] < \infty\). La integral estocástica de \(H\) respecto a la medida compensada de Poisson \(\tilde{N}\) está bien definida en \(L^2(\Omega, \mathbb{P})\) y constituye una martingala de cuadrado integrable centrada, cuya esperanza matemática es nula: \[ \mathbb{E}\left[ \int_0^T \int_{\mathbb{R}} H(t, z) \tilde{N}(dt, dz) \right] = 0 \]

De forma homóloga a la difusión continua, existe una isometría exacta para los saltos que permite controlar analíticamente las varianzas de los choques discretos.

Teorema 3.2 (Isometría de Itô para la Medida Compensada) Para todo integrando admisible \(H(t, z)\), la norma en el espacio de Hilbert \(L^2\) de la integral estocástica de salto satisface la siguiente identidad geométrica: \[ \mathbb{E}\left[ \left( \int_0^T \int_{\mathbb{R}} H(t, z) \tilde{N}(dt, dz) \right)^2 \right] = \mathbb{E}\left[ \int_0^T \int_{\mathbb{R}} |H(t, z)|^2 \nu(dz) dt \right] \]

Este resultado, documentado exhaustivamente por R. Situ (situ2005theory?), confirma que el segundo momento del ruido de saltos se comporta como una integral determinista sobre la medida de Lévy \(\nu(dz)\), habilitando el uso del cálculo diferencial para el análisis de riesgo.

3.5 Ecuaciones Diferenciales Estocásticas Continuas

Con el andamiaje de integración establecido, es posible formular ecuaciones que combinan una tendencia física determinista con perturbaciones aleatorias.

Definición 3.17 (Ecuación Diferencial Estocástica Clásica) Una ecuación diferencial estocástica continua para un proceso \(\{X(t)\}_{t \ge 0}\) es una relación simbólica expresada en su forma diferencial mediante:

\[ dX(t) = b(t, X(t)) dt + \sigma(t, X(t)) dW(t) \tag{3.1}\]

donde el término \(b(t, X(t))\) denota el coeficiente de deriva (tendencia determinista) y \(\sigma(t, X(t))\) representa el coeficiente de difusión (volatilidad).

El término \(dX(t)\) en la Ecuación 3.1 no debe interpretarse como una derivada ordinaria, sino como una representación abreviada de su ecuación integral equivalente, la cual otorga el verdadero sentido matemático a la igualdad:

\[ X(t) = X(0) + \int_0^t b(s, X(s)) ds + \int_0^t \sigma(s, X(s)) dW(s) \quad \text{casi seguramente.} \tag{3.2}\]

Para garantizar que el modelo matemático no resulte en comportamientos explosivos ni ambiguos (múltiples trayectorias cruzadas), se exige el cumplimiento de restricciones geométricas sobre los coeficientes.

Teorema 3.3 (Teorema Clásico de Existencia y Unicidad de Itô) Sea la EDE definida en la Ecuación 3.1 con una condición inicial \(X(0) = x_0\), medible respecto a \(\mathcal{F}_0\) e independiente del proceso de Wiener, con \(\mathbb{E}[|x_0|^2] < \infty\). Supóngase que para todo \(t \in [0, T]\) y estados \(x, y \in \mathbb{R}\), los coeficientes satisfacen las siguientes dos restricciones para constantes positivas \(K, L > 0\):

  1. Condición de Lipschitz Global: Las funciones no cambian tan bruscamente como para permitir bifurcaciones en el espacio de fase: \[ |b(t, x) - b(t, y)|^2 + |\sigma(t, x) - \sigma(t, y)|^2 \le L |x - y|^2 \]
  2. Condición de Crecimiento Lineal: El sistema no diverge a infinito en tiempo finito: \[ |b(t, x)|^2 + |\sigma(t, x)|^2 \le K (1 + |x|^2) \]

Bajo el cumplimiento de ambas condiciones, la ecuación tiene una solución fuerte global única \(\{X(t)\}_{t \in [0, T]}\), adaptada a la filtración \(\mathcal{F}_t\), con trayectorias continuas con probabilidad 1 (Karatzas y Shreve 1998).

Para transformar analíticamente las soluciones o funciones dependientes de una EDE continua, el cálculo tradicional se sustituye por la regla de la cadena estocástica.

Teorema 3.4 (Lema de Itô para Difusiones Continuas) Sea un proceso estocástico \(\{X(t)\}_{t \ge 0}\) que satisface la Ecuación 3.1, y sea \(V(t, x)\) una función escalar continuamente diferenciable en su componente temporal \(t\) (\(\mathcal{C}^1\)) y dos veces continuamente diferenciable en su componente espacial \(x\) (\(\mathcal{C}^2\)). El diferencial estocástico de la función compuesta viene dado por:

\[ dV(t, X(t)) = \left[ \frac{\partial V}{\partial t} + b(t, X(t))\frac{\partial V}{\partial x} + \frac{1}{2}\sigma^2(t, X(t))\frac{\partial^2 V}{\partial x^2} \right] dt + \sigma(t, X(t))\frac{\partial V}{\partial x} dW(t) \]

El término de segundo orden respecto a la derivada espacial es el núcleo de la corrección de Itô. Surge del hecho topológico de que la variación cuadrática del movimiento Browniano sobre un intervalo infinitesimal obedece la regla \((dW(t))^2 \to dt\) en un sentido probabilístico en \(L^2\).

3.5.1 El Proceso de Ornstein-Uhlenbeck Clásico

Como paso previo al desarrollo de nuestro modelo termodinámico final, es indispensable introducir un tipo particular de EDE que modela la inercia física y la atracción hacia un estado de equilibrio en un sistema cerrado.

Definición 3.18 (Proceso de Ornstein-Uhlenbeck) Un proceso estocástico \(\{X(t)\}_{t \ge 0}\) es un proceso de Ornstein-Uhlenbeck si satisface la siguiente ecuación diferencial estocástica lineal:

\[ dX(t) = \kappa (\theta - X(t)) dt + \sigma dW(t) \tag{3.3}\]

donde \(\kappa > 0\) representa la velocidad o tasa de reversión a la media, \(\theta \in \mathbb{R}\) denota el nivel asintótico de equilibrio a largo plazo y \(\sigma > 0\) es la magnitud del ruido térmico intrínseco.

La característica principal de la Ecuación 3.3 radica en su deriva lineal \(b(x) = \kappa(\theta - x)\). Cuando el estado del proceso supera el valor de equilibrio (\(X(t) > \theta\)), el término de deriva se vuelve estrictamente negativo, forzando a la trayectoria a descender; inversamente, si el proceso se encuentra por debajo del nivel de consigna (\(X(t) < \theta\)), la deriva se vuelve positiva, propulsando un crecimiento correctivo. Esta propiedad topológica de atracción (convergencia estocástica a la media) convierte a este proceso en la base fenomenológica ideal para simular la oscilación térmica de refrigeradores de vacunas regidos por la ley empírica de enfriamiento de Newton.

3.6 Herramientas Analíticas Auxiliares

Antes de formalizar la teoría de los sistemas estocásticos híbridos y proceder con la verificación de nuestro modelo, es necesario enunciar dos resultados clásicos del análisis matemático. Estas herramientas proporcionan el soporte lógico para acotar el crecimiento de las trayectorias estocásticas y para demostrar la unicidad de las soluciones.

Lema 3.2 (Desigualdad de Potencias (Cauchy-Schwarz elemental)) Para cualesquiera números reales \(a, b \in \mathbb{R}\) y para cualquier entero \(p \ge 1\), la convexidad de la función \(x \mapsto \vert{}x\vert{}^p\) implica la siguiente cota superior geométrica: \[\vert{}a \pm b\vert{}^p \le 2^{p-1} (\vert{}a\vert{}^p + \vert{}b\vert{}^p)\] En el contexto del análisis en \(L^2\) (donde \(p=2\)), esta desigualdad se reduce a la forma fundamental que utilizaremos para acotar el operador de deriva y varianza: \[\vert{}a \pm b\vert{}^2 \le 2\vert{}a\vert{}^2 + 2\vert{}b\vert{}^2\]

Lema 3.3 (Desigualdad Integral de Grönwall) Sea \(T > 0\) y sean \(u(t)\) y \(v(t)\) funciones reales, continuas y no negativas definidas en el intervalo \([0, T]\). Si existe una constante \(C \ge 0\) tal que para todo \(t \in [0, T]\) se cumple la desigualdad integral: \[u(t) \le C + \int_0^t v(s) u(s) ds\] Entonces, la función \(u(t)\) está estrictamente acotada por la función exponencial de la integral de \(v(t)\): \[u(t) \le C \exp\left( \int_0^t v(s) ds \right)\]

En la teoría de ecuaciones diferenciales estocásticas, el Lema de Grönwall se utiliza asumiendo que \(u(t)\) representa la esperanza matemática de la diferencia al cuadrado entre dos posibles soluciones, i.e., \(u(t) = \mathbb{E}[\vert{}X_1(t) - X_2(t)\vert{}^2]\). Si se logra demostrar que \(u(t) \le 0 + \int L u(s)ds\), el lema dictamina que \(u(t) \le 0 \cdot e^{Lt} = 0\), probando así la unicidad casi segura de la solución.

3.7 Sistemas Híbridos: Discontinuidades y Cambios de Régimen

Los modelos de difusión continua resultan insuficientes cuando el fenómeno físico exhibe transiciones estructurales de entorno (como un fallo eléctrico general) y choques discretos instantáneos (como la apertura de una puerta). La amalgama de estos comportamientos da lugar a un sistema híbrido impulsado por medidas de salto.

Definición 3.19 (Ecuación Diferencial Estocástica Híbrida) Sea \(\alpha(t)\) una cadena de Markov a tiempo continuo en un espacio de estados finito \(\mathcal{M}\). Una EDE híbrida con saltos es una ecuación gobernada por un régimen markoviano y perturbada por una medida de Poisson compensada \(\tilde{N}(dt, dz) = N(dt, dz) - \nu(dz)dt\), cuya forma diferencial es:

\[dX(t) = b(t, X(t^-), \alpha(t^-)) dt + \sigma(t, X(t^-), \alpha(t^-)) dW(t) + \int_{\mathbb{R}} \gamma(t, X(t^-), \alpha(t^-), z) \tilde{N}(dt, dz)\]

Dado que la función objetivo presenta discontinuidades puntuales, el teorema fundamental de Itô debe expandirse.

Teorema 3.5 (Fórmula de Itô Generalizada para Sistemas Híbridos) Sea \(V(t, x, i)\) una función continuamente diferenciable en el tiempo \(t\) (\(\mathcal{C}^1\)) y dos veces continuamente diferenciable en el espacio \(x\) (\(\mathcal{C}^2\)) para cada régimen operativo \(i \in \mathcal{M}\). Si \(X(t)\) es un proceso que satisface la EDE híbrida descrita anteriormente, el diferencial estocástico de la función compuesta viene dado por:

\[\begin{aligned} dV(t, X(t), \alpha(t)) = & \left[ \frac{\partial V}{\partial t} + \frac{\partial V}{\partial x}b(t, X, \alpha) + \frac{1}{2}\frac{\partial^2 V}{\partial x^2}\sigma^2(t, X, \alpha) + \sum_{j \in \mathcal{M}} q_{\alpha(t)j} V(t, X, j) \right] dt \\ & + \int_{\mathbb{R}} \left[ V(t, X(t^-) + \gamma, \alpha(t^-)) - V(t, X(t^-), \alpha(t^-)) - \frac{\partial V}{\partial x}\gamma(t, X(t^-), \alpha(t^-), z) \right] \nu(dz) dt \\ & + \frac{\partial V}{\partial x}\sigma(t, X, \alpha) dW(t) \\ & + \int_{\mathbb{R}} \left[ V(t, X(t^-) + \gamma, \alpha(t^-)) - V(t, X(t^-), \alpha(t^-)) \right] \tilde{N}(dt, dz) \end{aligned}\]

Esta formulación rigurosa añade al operador diferencial clásico una sumatoria ponderada por la matriz de transición \(Q\) y un operador de diferencias finitas que absorbe las discontinuidades generadas por la medida de salto espacial \(\nu(dz)\).

3.7.1 Teoremas de Existencia y Unicidad Híbrida

Para garantizar que un sistema estocástico híbrido posea viabilidad analítica, la existencia y unicidad de sus soluciones se construyen en dos fases teóricas: primero garantizando el comportamiento frente a los saltos de Poisson, y luego concatenando la solución a través de los cambios de régimen de la cadena de Markov.

Teorema 3.6 (Teorema de Existencia y Unicidad con Saltos de Poisson (Teorema 117 de R. Situ)) Para un régimen estático \(\alpha(t) = i\), sea la ecuación diferencial estocástica \(dX(t) = b(t, X(t^-))dt + \sigma(t, X(t^-))dW(t) + \int_{\mathbb{R}} \gamma(t, X(t^-), z) \tilde{N}(dt, dz)\). Supóngase que los coeficientes satisfacen de manera estricta las siguientes dos condiciones para constantes \(K, L > 0\):

  1. Condición de Lipschitz Global: \[\vert{}b(t, x) - b(t, y)\vert{}^2 + \vert{}\sigma(t, x) - \sigma(t, y)\vert{}^2 + \int_{\mathbb{R}} \vert{}\gamma(t, x, z) - \gamma(t, y, z)\vert{}^2 \nu(dz) \le L \vert{}x - y\vert{}^2\]
  2. Condición de Crecimiento Lineal: \[\vert{}b(t, x)\vert{}^2 + \vert{}\sigma(t, x)\vert{}^2 + \int_{\mathbb{R}} \vert{}\gamma(t, x, z)\vert{}^2 \nu(dz) \le K (1 + \vert{}x\vert{}^2)\]

Entonces, para cualquier condición inicial \(\mathcal{F}_0\)-medible tal que \(\mathbb{E}[\vert{}X(0)\vert{}^2] < \infty\), la EDE admite una solución fuerte global y única, con trayectorias càdlàg casi seguramente.

Una vez garantizada la solución bajo un régimen constante mediante la métrica de R. Situ (situ2005theory?), la validación global del sistema híbrido se obtiene mediante la técnica de empalme topológico en los tiempos de parada estocásticos de la cadena de Markov, tal como fue formalizado por Mao y Yuan, y Yin y Zhu (Yin y Zhu 2010).

Teorema 3.7 (Teorema de Concatenación de Soluciones Híbridas (Switching Markoviano)) Sea \(\alpha(t)\) una cadena de Markov en tiempo continuo sobre un espacio de estados finito \(\mathcal{M}\), definida por una matriz generadora acotada \(Q\). Sean \(0 = \tau_0 < \tau_1 < \tau_2 < \dots\) los tiempos de parada aleatorios correspondientes a los saltos de régimen de \(\alpha(t)\).

Puesto que el espacio de estados es finito y las tasas de transición \(q_{ij}\) están acotadas, la cadena es no explosiva, es decir, \(\mathbb{P}(\lim_{k \to \infty} \tau_k = \infty) = 1\). Si en cada intervalo aleatorio \([\tau_k, \tau_{k+1})\) el sistema satisface las condiciones del @thm-situ-existencia para el régimen estacionario \(i_k \in \mathcal{M}\), la solución puede ser concatenada de forma iterativa tomando el límite por la izquierda \(\lim_{t \uparrow \tau_k} X^{(k-1)}(t)\) como la nueva condición inicial fuerte \(X^{(k)}(\tau_k)\).

En consecuencia, el sistema híbrido global posee una única solución fuerte bien definida para todo \(t \in [0, \infty)\), y las trayectorias no divergen a infinito en tiempo finito.

3.8 El Modelo Estocástico Termodinámico (Ornstein-Uhlenbeck Híbrido)

Habiendo establecido el marco analítico de las ecuaciones diferenciales estocásticas con discontinuidades y cambios de régimen, procedemos a formalizar la ecuación que rige la dinámica térmica del refrigerador de vacunas.

Bajo los principios termodinámicos de la ley de enfriamiento de Newton, la temperatura interna \(T(t)\) del equipo se modela mediante una EDE de Ornstein-Uhlenbeck sujeta a perturbaciones gaussianas, saltos discretos y un estado de suministro eléctrico dictado por una cadena de Markov \(\alpha(t) \in \mathcal{M} = \{1, 2\}\):

\[dT(t) = b(t, T(t^-), \alpha(t^-)) dt + \sigma(T(t^-), \alpha(t^-)) dW(t) + dJ(t)\] {#eq-modelo-termodinamico}

Donde los regímenes operativos se definen como \(\alpha(t) = 1\) (suministro eléctrico activo) y \(\alpha(t) = 2\) (corte de energía). Los coeficientes de deriva \(b\) y difusión \(\sigma\) toman las siguientes formas paramétricas:

Régimen 1 (Con energía): \[b(t, T, 1) = \kappa_{on}(\theta_{set} - T)\] \[\sigma(T, 1) = \sigma_{on}\]

Régimen 2 (Falla eléctrica): \[b(t, T, 2) = \kappa_{off}(T_{amb}(t) - T)\] \[\sigma(T, 2) = \sigma_{off}\]

El término \(dJ(t)\) representa un proceso de Poisson compuesto que inyecta calor al sistema producto de las aperturas de la puerta por el personal médico. Ocurre exclusivamente en el Régimen 1, dictado por un proceso de Poisson no homogéneo con tasa \(\lambda(t)\). La magnitud de cada salto \(\gamma_i\) es una variable aleatoria extraída de una distribución normal truncada \(Z \sim \mathcal{N}(0.76, 0.20^2)\) tal que \(\gamma_i = \max(0.16, Z)\).

3.8.1 Transformación Analítica de la Medida de Salto

Para someter nuestro modelo a los criterios de existencia y unicidad del @thm-situ-existencia, debemos reescribir el diferencial del proceso de Poisson compuesto \(dJ(t)\) en términos de la medida de Poisson compensada \(\tilde{N}(dt, dz)\). Invocando el @lem-equivalencia-saltos, definimos la medida de intensidad \(\nu(dz) = \lambda(t) dF(z)\), donde \(F(z)\) es la función de distribución acumulada de los saltos \(\gamma_i\).

Transformamos el diferencial de salto sumando y restando el compensador determinista: \[dJ(t) = \int_{\mathbb{R}} z N(dt, dz) = \int_{\mathbb{R}} z \tilde{N}(dt, dz) + \left( \lambda(t) \int_{\mathbb{R}} z dF(z) \right) dt\]

Dado que la integral respecto a la distribución de probabilidad \(dF(z)\) es el valor esperado de la magnitud del salto térmico, \(\mathbb{E}[\gamma]\), la ecuación puede reescribirse absorbiendo este término determinista en una “deriva modificada” \(\tilde{b}(t, T, \alpha)\):

Deriva Compensada: \[\tilde{b}(t, T, 1) = \kappa_{on}(\theta_{set} - T) + \lambda(t)\mathbb{E}[\gamma]\] \[\tilde{b}(t, T, 2) = \kappa_{off}(T_{amb}(t) - T)\]

La ecuación híbrida en su forma final y estrictamente compatible con la teoría clásica de saltos es:

\[dT(t) = \tilde{b}(t, T(t^-), \alpha(t^-)) dt + \sigma(\alpha(t^-)) dW(t) + \int_{\mathbb{R}} \gamma(\alpha(t^-), z) \tilde{N}(dt, dz)\] {#eq-modelo-compensado}

3.9 Verificación Analítica de Existencia y Unicidad

Para demostrar que la ?eq-modelo-compensado posee una solución fuerte, única y global, procedemos a verificar analíticamente que sus coeficientes satisfacen las condiciones del @thm-situ-existencia y del @thm-mao-switching.

Paso 1: Localización del Intervalo de Análisis Sea \(\tau_k\) la secuencia de tiempos de parada estocásticos donde la cadena \(\alpha(t)\) conmuta de régimen. Puesto que el espacio de estados es finito (\(m=2\)) y las tasas de la matriz de transición de fallos eléctricos no son infinitas, la cadena es no explosiva (\(\tau_k \to \infty\) casi seguramente). Evaluaremos el sistema condicionado en el intervalo \([\tau_k, \tau_{k+1})\), donde el régimen \(\alpha(t) = i \in \{1, 2\}\) es constante.

Paso 2: Comprobación de la Condición de Lipschitz Global Debemos demostrar que la tasa de cambio de la ecuación está acotada por la diferencia de los estados. Sean \(T_1\) y \(T_2\) dos temperaturas internas arbitrarias. Evaluamos la diferencia cuadrática de los coeficientes:

  1. Difusión: Dado que \(\sigma_{on}\) y \(\sigma_{off}\) son constantes reales independientes del estado \(T\), se cumple trivialmente que: \[\vert{}\sigma(i) - \sigma(i)\vert{}^2 = 0\]

  2. Medida Espacial de Saltos: Puesto que la magnitud de la masa de aire que ingresa al abrir la puerta (\(\gamma=z\)) depende exclusivamente del entorno externo y no de la temperatura interna actual \(T(t^-)\), la diferencia espacial es nula: \[\int_{\mathbb{R}} \vert{}\gamma(i, z) - \gamma(i, z)\vert{}^2 \nu(dz) = \int_{\mathbb{R}} \vert{}z - z\vert{}^2 \lambda(t) dF(z) = 0\]

  3. Deriva Compensada: Para el Régimen 1, evaluamos la diferencia absoluta al cuadrado. Nótese que el término estocástico esperado \(\lambda(t)\mathbb{E}[\gamma]\) se cancela algebraicamente: \[\vert{}\tilde{b}(t, T_1, 1) - \tilde{b}(t, T_2, 1)\vert{}^2 = \left\vert{} (\kappa_{on}(\theta_{set} - T_1) + \lambda(t)\mathbb{E}[\gamma]) - (\kappa_{on}(\theta_{set} - T_2) + \lambda(t)\mathbb{E}[\gamma]) \right\vert{}^2\] \[= \vert{}-\kappa_{on}(T_1 - T_2)\vert{}^2 = \kappa_{on}^2 \vert{}T_1 - T_2\vert{}^2\] De manera análoga, para el Régimen 2 obtenemos \(\kappa_{off}^2 \vert{}T_1 - T_2\vert{}^2\).

Definiendo la constante global de Lipschitz como la máxima inercia térmica al cuadrado, \(L = \max(\kappa_{on}^2, \kappa_{off}^2)\), se satisface estrictamente: \[\vert{}\tilde{b}(t, T_1, i) - \tilde{b}(t, T_2, i)\vert{}^2 + \vert{}\sigma(i) - \sigma(i)\vert{}^2 + \int_{\mathbb{R}} \vert{}\gamma(i, z) - \gamma(i, z)\vert{}^2 \nu(dz) \le L \vert{}T_1 - T_2\vert{}^2\] Esta acotación garantiza matemáticamente que las trayectorias de temperatura no se intersectan (unicidad).

Paso 3: Comprobación de la Condición de Crecimiento Lineal Debemos probar que el crecimiento del sistema está termodinámicamente acotado para prevenir explosiones en tiempo finito. Para la deriva en el Régimen 1, empleamos la desigualdad algebraica del @lem-desigualdad-algebraica \((\vert{}a-b\vert{}^2 \le 2\vert{}a\vert{}^2 + 2\vert{}b\vert{}^2)\) asumiendo una cota máxima para la tasa de apertura de puertas \(\lambda_{max}\): \[\vert{}\tilde{b}(t, T, 1)\vert{}^2 = \vert{}\kappa_{on}\theta_{set} + \lambda(t)\mathbb{E}[\gamma] - \kappa_{on}T\vert{}^2 \le 2(\kappa_{on}\theta_{set} + \lambda_{max}\mathbb{E}[\gamma])^2 + 2\kappa_{on}^2 \vert{}T\vert{}^2\]

Para el Régimen 2, definimos \(T_{max}\) como la temperatura ambiental histórica máxima absoluta de la ubicación geográfica (i.e., \(\vert{}T_{amb}(t)\vert{} \le T_{max}\)), obteniendo: \[\vert{}\tilde{b}(t, T, 2)\vert{}^2 = \vert{}\kappa_{off}T_{amb}(t) - \kappa_{off}T\vert{}^2 \le 2\kappa_{off}^2 T_{max}^2 + 2\kappa_{off}^2 \vert{}T\vert{}^2\]

Evaluando el segundo momento de la medida de saltos (varianza de las perturbaciones), denotando \(\mathbb{E}[\gamma^2] = M_\gamma\): \[\int_{\mathbb{R}} \vert{}\gamma(i, z)\vert{}^2 \nu(dz) = \lambda(t) \int_{\mathbb{R}} z^2 dF(z) = \lambda(t) \mathbb{E}[\gamma^2] \le \lambda_{max} M_\gamma\]

Agrupando todos los términos (deriva, volatilidad constante \(\Sigma_{max} = \max(\sigma_{on}^2, \sigma_{off}^2)\) y saltos) y factorizando, se demuestra que existe una constante estática de crecimiento \(K\): \[K = \max \left( \max[2(\kappa_{on}\theta_{set} + \lambda_{max}\mathbb{E}[\gamma])^2, 2\kappa_{off}^2 T_{max}^2] + \Sigma_{max} + \lambda_{max} M_\gamma, \quad \max(2\kappa_{on}^2, 2\kappa_{off}^2) \right)\] Tal que se cumple rigurosamente: \[\vert{}\tilde{b}(t, T, i)\vert{}^2 + \vert{}\sigma(i)\vert{}^2 + \int_{\mathbb{R}} \vert{}\gamma(i, z)\vert{}^2 \nu(dz) \le K(1 + \vert{}T\vert{}^2)\] Esta cota demuestra que el intercambio de calor está físicamente limitado, garantizando que el proceso \(T(t)\) es globalmente estable.

Paso 4: Concatenación Global y Conclusión Habiendo demostrado las condiciones de Lipschitz y Crecimiento Lineal en los pasos 2 y 3, el @thm-situ-existencia avala que, en el intervalo \([\tau_k, \tau_{k+1})\), la EDE posee una solución fuerte y única. Al ser la cadena de Markov no explosiva, el @thm-mao-switching nos permite aplicar el lema de Grönwall iterativamente en los límites de salto para concatenar las soluciones hasta el infinito. En conclusión, el modelo estocástico propuesto de red de frío posee una trayectoria global única, continua por la derecha, validando su implementación para el análisis inferencial mediante métodos de Monte Carlo.
